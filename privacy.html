Никакие. Сайт:

  • не использует cookies;
  • не подключает системы аналитики, рекламные сети, пиксели и счётчики;
  • не загружает сторонние шрифты, скрипты и изображения — все ресурсы лежат на самом сайте;

3. Локальное хранилище браузера

Чтобы отметки в чек-листе не пропадали после перезагрузки страницы, сайт сохраняет их в локальном хранилище (localStorage) вашего браузера. Эти данные хранятся только на вашем устройстве, не отправляются на сервер и недоступны владельцу сайта. Вы можете удалить их в любой момент кнопкой «Сбросить отметки» или очисткой данных сайта в настройках браузера.

4. Хостинг

Сайт размещён на GitHub Pages. Как любой хостинг-провайдер, GitHub может обрабатывать технические данные при обращении к сайту (например, IP-адрес и сведения о запросе) в соответствии со своей собственной политикой. Владелец сайта не имеет доступа к этим данным в виде персональной статистики посетителей. Подробнее: Заявление GitHub о конфиденциальности.

5. Внешние ссылки

Сайт может содержать ссылки на сторонние ресурсы. Мы не контролируем их содержание и политику конфиденциальности и рекомендуем знакомиться с ними отдельно.

6. Дети

Сайт не собирает данные о пользователях, в том числе о детях, и не предназначен для сбора персональной информации.

7. Ваши права

Поскольку персональные данные не собираются, удалять или исправлять на стороне сайта нечего. Если у вас есть вопросы о конфиденциальности, напишите владельцу через контакт, указанный в разделе 1.

8. Изменения политики

Мы можем обновлять эту политику. Актуальная версия всегда доступна на этой странице, дата последнего обновления указана вверху.
