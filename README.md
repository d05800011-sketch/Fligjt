# ✈ Памятка пассажира

Бесплатный сайт-памятка: что взять в самолёт, что нельзя в ручную кладь, этапы подготовки к рейсу и интерактивный чек-лист.

- Цвета: белый и голубой, градиентные кнопки
- Без cookies, аналитики, рекламы и внешних ресурсов
- Строгая политика безопасности контента (CSP) в каждой странице
- Работает на чистом HTML/CSS/JS, без сборки

## Публикация бесплатно на GitHub Pages

1. Зайдите на https://github.com/new и создайте **публичный** репозиторий (например, `passenger-memo`).
2. Нажмите **uploading an existing file** и загрузите все файлы из этой папки:
   `index.html`, `style.css`, `app.js`, `favicon.svg`, `privacy.html`, `terms.html`, `.nojekyll`, `LICENSE`, `README.md`.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**
   - Нажмите **Save**.
4. Через 1–2 минуты сайт появится по адресу `https://ВАШ-НИК.github.io/passenger-memo/`.

## Что нужно заполнить перед публикацией

В файлах `privacy.html` и `terms.html` найдите жёлтые поля `[...]` и впишите:

- имя или псевдоним владельца сайта;
- ссылку на ваш репозиторий (для связи через Issues).

В `LICENSE` замените `[ВАШЕ ИМЯ]` на своё.

## Как редактировать список вещей

Список пунктов находится в начале файла `app.js` (массив `ITEMS`). Добавляйте строки в формате:

```js
["категория", "Название", "Подсказка (можно пустую)"]
```

Категории: `docs`, `carry`, `tech`, `health`, `comfort`, `bag`.

Если меняете количество пунктов, обновите число «29» в `index.html` (блок статистики и строка «0 из 29»).
